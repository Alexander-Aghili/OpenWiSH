**Design**

The policy has three parts, and it gives up any action that would get the cannon hit.

1. **Dodge.** Enemy bullets are found as channel 1 minus channel 2 (danger that is not an alien). Only rows 6 to 8 are watched, which gives 3 steps of warning and protects against sticky actions. At most one enemy bullet is on screen at a time, so four units (18–21) compute the step function of d = (bullet column) − (cannon column) at thresholds −1.5, −0.5, 0.5 and 1.5. Each unit is gated off when no bullet is present.
   - d = 0 means staying is fatal, so the cannon must move. The escape side is the block's direction of travel (gauge channel), forced inward at the walls.
   - d = −1 blocks moving left, and d = +1 blocks moving right.
2. **Aim (2 or more aliens).** Units 0–8 handle "move right" for cannon position p, and units 9–17 handle "move left". Each unit is gated by the cannon one-hot and fires only when column p holds no alien. The direction is chosen by majority: right if the number of aliens to the right is at least the number to the left. While the cannon crosses empty columns this count does not change, so it never oscillates. When neither unit fires, an alien is overhead.
   - The cannon fires if that is true and the cooldown is clear. The cooldown counts as clear when there is no friendly bullet in rows 5 to 8, which matches the 5-frame shot timer.
3. **Lead shot (1 alien).** A lone alien moves every frame. For every cell and direction I worked out the cannon column x from which a shot fired now meets the alien, bounces included (15 means no hit is possible).
   - These columns are the weights of a linear sum T, and two units test T = cannon column.
   - The test is gated so it only works when exactly one alien is left.
   - Movement is switched off then: the cannon waits, because T sweeps past every column.

Layer 2 combines these into AND units: fire-here, fire-lead, move-R, move-L, danger-stay/left/right, dodge-R and dodge-L. The output gives no-op a +5 base, so the cannon waits by default. Fire gets +11, move +10 and dodge +14, while a fatal move gets −25 and staying in danger −20. Up and down get −20.
